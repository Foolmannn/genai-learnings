# Embedding Models in LangChain (Detailed)

Embeddings are one of the most important concepts in modern AI systems like **RAG (Retrieval-Augmented Generation)**, semantic search, recommendation systems, document retrieval, and chatbots with memory.

Think of embeddings as:

> Converting text into numbers (vectors) that preserve meaning.

Example:

```text
"Dog"      → [0.21, -0.8, 1.2, ...]
"Puppy"    → [0.25, -0.75, 1.18, ...]
"Airplane" → [-0.4, 0.91, -1.5, ...]
```

Since **dog** and **puppy** have similar meaning:

```text
distance(dog, puppy)
      ↓
small
```

while:

```text
distance(dog, airplane)
      ↓
large
```

The closer vectors are, the more semantically similar the texts are.

---

# 1. Why embeddings?

Suppose you have documents:

```text
Doc1:
"PyTorch is a deep learning framework"

Doc2:
"Cricket is popular in Nepal"

Query:
"Machine learning library"
```

Keyword search:

```text
"machine learning"
```

might fail.

Embedding search understands meaning:

```text
PyTorch ≈ ML library
```

and retrieves Doc1.

---

# 2. How embeddings work

Pipeline:

```text
Text
 ↓
Embedding model
 ↓
Vector (numbers)
 ↓
Store in vector DB
 ↓
Similarity search
 ↓
Retrieve relevant docs
```

Example:

```text
"cat"
↓

[0.1, 0.5, -0.3]

"kitten"
↓

[0.12,0.47,-0.28]
```

These vectors are close.

# 4. Using OpenAI embeddings

Import:

```python
from langchain_openai import OpenAIEmbeddings
```

Initialize:

```python
embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small"
)
```

Generate embedding:

```python
vector = embeddings.embed_query(
    "What is machine learning?"
)

print(len(vector))
```

Output:

```text
1536
```

Meaning:

```text
Sentence
↓

1536-dimensional vector
```

Example:

```python
print(vector[:5])
```

Output:

```text
[0.12,-0.44,0.91,...]
```

---

## embed_query()

Used for user search queries.

```python
query_vector = embeddings.embed_query(
    "Explain tensors"
)
```

Input:

```text
String
```

Output:

```text
List[float]
```

---

## embed_documents()

Embeds multiple texts.

Example:

```python
documents = [
    "PyTorch tutorial",
    "Football news",
    "Machine learning"
]

vectors = embeddings.embed_documents(
    documents
)

print(len(vectors))
```

Output:

```text
3
```

Each document gets a vector.

---

Visual:

```text
[
 "PyTorch",
 "Football",
 "ML"
]

↓

[
 [0.1,0.2,...],
 [0.7,-0.1,...],
 [-0.2,0.8,...]
]
```

# 5. Difference between embed_query and embed_documents

| Method            | Purpose          |
| ----------------- | ---------------- |
| embed_query()     | User searches    |
| embed_documents() | Documents stored |

Sometimes models process them differently.

# 7. Similarity search

Suppose:

Documents:

```text
1: PyTorch tutorial
2: Football news
3: Deep learning guide
```

Embeddings:

```text
doc1 → vector1
doc2 → vector2
doc3 → vector3
```

Query:

```text
"ML framework"
```

↓

Convert query to vector:

```text
query_vector
```

Compute similarity:

```text
cosine(query, doc1)
cosine(query, doc2)
cosine(query, doc3)
```

Return highest.

---

# 8. Cosine similarity

Measures vector closeness.

Formula:

\cos(\theta)=\frac{A\cdot B}{||A||,||B||}

Values:

```text
1     → identical
0     → unrelated
-1    → opposite
```

---

Example:

```python
from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

v1 = np.array([[1,2,3]])
v2 = np.array([[1,2,4]])

similarity = cosine_similarity(v1,v2)

print(similarity)
```

# 9. Embeddings + Vector DB in LangChain

Common vector databases:

* FAISS
* Chroma
* Pinecone
* Weaviate

Example with FAISS:

Install:

```bash
pip install faiss-cpu
```

Create vector DB:

```python
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings

documents = [
    "PyTorch tutorial",
    "Cricket news",
    "Machine learning"
]

embeddings = OpenAIEmbeddings()

db = FAISS.from_texts(
    documents,
    embeddings
)
```

Search:

```python
results = db.similarity_search(
    "deep learning framework",
    k=2
)

print(results)
```

---

Flow:

```text
Documents
 ↓
Embeddings
 ↓
Vector DB
 ↓
Similarity search
 ↓
Relevant docs
```

This is the basis of **RAG**.

# 10. Embeddings in RAG

RAG pipeline:

```text
User Query
      ↓
Embedding model
      ↓
Vector DB search
      ↓
Relevant docs
      ↓
LLM
      ↓
Answer
```

Without embeddings:

```text
LLM hallucinates
```

With embeddings:

```text
LLM uses retrieved knowledge
```

# 11. Complete LangChain example

```python
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS


docs = [
    "PyTorch is a deep learning library",
    "Nepal is in South Asia",
    "LangChain helps build LLM apps"
]

embeddings = OpenAIEmbeddings()

db = FAISS.from_texts(
    docs,
    embeddings
)

results = db.similarity_search(
    "machine learning framework",
    k=1
)

print(results[0].page_content)
```

Output:

```text
PyTorch is a deep learning library
```
