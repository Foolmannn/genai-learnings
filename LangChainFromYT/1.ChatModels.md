In LangChain, **LLMs** and **Chat Models** are two different abstractions for interacting with language models.

* **LLMs** → take a **string input** and return a **string output**
* **Chat Models** → take a **list of messages** (system, human, AI) and return a **message**

Think of it like:

```text
LLM:
Input: "Explain machine learning"
Output: "Machine learning is..."

Chat Model:
Input:
[
 HumanMessage("Explain machine learning")
]
Output:
AIMessage("Machine learning is...")
```

Most modern models (GPT, Claude, Gemini) work better as **chat models**.

# 2. Using LLMs in LangChain

Older completion-style models use `LLM`.

Example:

```python
from langchain_openai import OpenAI

llm = OpenAI(
    model="gpt-3.5-turbo-instruct",
    temperature=0.7
)

response = llm.invoke(
    "Explain tensors in machine learning"
)

print(response)
```

Output:

```text
Tensors are multidimensional arrays...
```

Here:

```python
llm.invoke(prompt)
```

takes:

```python
str → str
```

---

## Parameters

### Temperature

Controls randomness.

```python
llm = OpenAI(
    model="gpt-3.5-turbo-instruct",
    temperature=0
)
```

Temperature:

```text
0    = deterministic
0.5  = balanced
1    = creative
2    = very random
```

---

### Max Tokens

Limits response size:

```python
llm = OpenAI(
    max_tokens=100
)
```

# 3. Using Chat Models

Chat models use **messages**.

Import:

```python
from langchain_openai import ChatOpenAI
```

Create model:

```python
chat = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0
)
```

Invoke:

```python
response = chat.invoke(
    "Explain tensors"
)

print(response.content)
```

Output:

```text
Tensors are multidimensional arrays...
```

Notice:

```python
response.content
```

because result is an `AIMessage`.

---

# 4. Chat Messages

Chat models support roles:

* System
* Human
* AI

Example:

```python
from langchain_core.messages import (
    SystemMessage,
    HumanMessage
)

messages = [
    SystemMessage(
        content="You are a ML teacher"
    ),

    HumanMessage(
        content="Explain tensors"
    )
]

response = chat.invoke(messages)

print(response.content)
```

---

The model sees:

```text
System:
You are ML teacher

User:
Explain tensors
```

System messages define behavior.

Example:

```python
SystemMessage(
    content="Answer in one sentence"
)
```

# 5. Multi-turn Conversation

You can store history manually.

```python
messages = [
    SystemMessage(
        content="You are helpful"
    ),

    HumanMessage(
        content="My name is Suman"
    )
]

response = chat.invoke(messages)

messages.append(response)

messages.append(
    HumanMessage(
        content="What is my name?"
    )
)

response2 = chat.invoke(messages)

print(response2.content)
```

Output:

```text
Your name is Suman.
```

Conversation history matters.

# 6. Difference: LLM vs Chat Model

| Feature         | LLM               | Chat Model      |
| --------------- | ----------------- | --------------- |
| Input           | String            | Messages        |
| Output          | String            | AIMessage       |
| Context/history | Manual            | Natural         |
| Roles           | No                | Yes             |
| Modern models   | Rare              | Common          |
| Best for        | Simple completion | Agents/chatbots |

---

Example:

LLM:

```python
response = llm.invoke(
    "Write poem"
)
```

Chat:

```python
response = chat.invoke([
    HumanMessage(
        content="Write poem"
    )
])

print(response.content)
```

# 7. Prompt Templates with Chat Models

Instead of hardcoding:

```python
chat.invoke(
    "Explain CNN"
)
```

Use templates:

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_template(
    "Explain {topic}"
)

chain = prompt | chat

response = chain.invoke(
    {"topic":"CNN"}
)

print(response.content)
```

This is a **LangChain Expression Language (LCEL)** pipeline:

```text
Prompt → Model → Output
```

# 8. Output Parsing

Convert model output:

```python
from langchain_core.output_parsers import StrOutputParser

chain = (
    prompt
    | chat
    | StrOutputParser()
)

result = chain.invoke(
    {"topic":"Transformers"}
)

print(result)
```

Now:

```text
AIMessage → String
```

---

# 9. Full Example

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser


chat = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0
)

prompt = ChatPromptTemplate.from_template(
    "Explain {topic} in simple words"
)

chain = (
    prompt
    | chat
    | StrOutputParser()
)

response = chain.invoke(
    {"topic":"PyTorch tensors"}
)

print(response)
```

Flow:

```text
User Input
      ↓
Prompt Template
      ↓
Chat Model
      ↓
Parser
      ↓
Final String
```

# 10. Which should you learn?

For modern LangChain:

1. **ChatOpenAI / Chat Models** ← learn first
2. Prompt Templates
3. LCEL (`|`)
4. Output Parsers
5. Memory
6. Chains
7. Retrieval (RAG)
8. Agents

Most production apps use **chat models**, not old `LLM` classes.

Since you're learning ML and building projects, chat models + LCEL + RAG are likely the highest-value next steps.
